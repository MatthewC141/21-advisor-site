How it works: for every distinct move (including STAY a column, then place) the advisor plays out the rest of the game thousands of times over random orders of the cards still unseen, using a trained fast policy for later moves, and scores each finished game on this game's payout curve. All moves share the same simulated futures, so the gaps between them are measured tightly. Near the max it plays safe; far below it takes more risk.
